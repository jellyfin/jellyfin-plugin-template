Random Reel

Random clip playback from folders and playlists

How many minutes each randomly selected clip will play. Default: 10.
Minutes to skip at the start and end of each video when choosing the random start position. Default: 5.
If unchecked, each video will be played at most once before the pool is exhausted and resets.

API Usage

GET /Random Reel/Next?folderId={id}&sessionId={session}
Returns the next item to play with itemId, startPositionTicks, and playbackDurationTicks.

POST /Random Reel/Session/Reset?folderId={id}&sessionId={session}
Clears the played-items history for the session.
